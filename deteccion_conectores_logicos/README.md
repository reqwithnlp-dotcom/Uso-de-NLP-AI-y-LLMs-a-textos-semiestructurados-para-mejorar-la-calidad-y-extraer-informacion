#Descripción

Este proyecto implementa un detector de conectores lógicos en inglés utilizando Python.



#Instalación

Requisitos previos

Tener instalado:

Python 3.10 o superior

Verificar instalación:

python --version

Clonar el repositorio:

git clone <URL_DEL_REPOSITORIO>
cd <NOMBRE_DEL_REPOSITORIO>



#Ejecución del servicio
Ejecutar el detector:

python main.py


Uso
Ejemplo 1
Input
Dog and cat or rabbit
Output esperado
Connectors: [('and', 'addition'), ('or', 'disjunction')]


#Parámetros esperados
Parámetro:text	
Tipo:String
