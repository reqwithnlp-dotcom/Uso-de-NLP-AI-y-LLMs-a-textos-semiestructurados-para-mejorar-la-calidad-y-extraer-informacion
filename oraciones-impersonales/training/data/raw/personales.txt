# ORACIONES PERSONALES
#
# Una oración por línea, con punto final.
# Las líneas vacías y las que empiezan con # se ignoran.
# No numeres las líneas (nada de "1." ni "-").
#
# Objetivo: variedad de sujetos y estructuras. La sección 5 (hard negatives)
# es la MÁS VALIOSA: son las que el modelo confunde. Cargala bien.


# ---------------------------------------------------------------------------
# 1. SUJETO PRONOMINAL  (I / you / he / she / we / they)
# ---------------------------------------------------------------------------
I bought a car last week.
They won the match without any trouble.


# ---------------------------------------------------------------------------
# 2. SUJETO NOMINAL  (nombre propio o sustantivo)
# ---------------------------------------------------------------------------
John fixed the engine yesterday.
The dog barks every morning.


# ---------------------------------------------------------------------------
# 3. SUJETO INDEFINIDO  (someone / somebody / nobody / everyone ...)
# ---------------------------------------------------------------------------
Someone called you this afternoon.
Nobody noticed the change in the report.


# ---------------------------------------------------------------------------
# 4. IMPERATIVOS  (sujeto "you" implícito)
# ---------------------------------------------------------------------------
Open the door before you leave.
Check the configuration file first.


# ---------------------------------------------------------------------------
# 5. HARD NEGATIVES  <-- LOS MÁS IMPORTANTES
#    "it" REFERENCIAL: parecen impersonales pero NO lo son, porque "it"
#    remite a algo concreto mencionado antes (un objeto, un programa...).
# ---------------------------------------------------------------------------
It works perfectly on my laptop.
It belongs to my brother.
It runs smoothly after the update.


# ---------------------------------------------------------------------------
# 6. SUBORDINADAS  (que NO deben confundir: la raíz manda)
#    "She said that..." tiene sujeto real, aunque use un verbo de reporte.
# ---------------------------------------------------------------------------
She said that he was late again.
The weather is cold in my room.
